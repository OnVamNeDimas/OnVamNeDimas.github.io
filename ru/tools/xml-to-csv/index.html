XML в CSV

XML обрабатывается в браузере; код преобразования этого инструмента не отправляет XML на сервер приложения.

Пустые значения — пустые ячейки; вложенные поля используют точки, повторяющиеся значения сохраняются как JSON.

Формулоподобные значения после начальных пробелов или управляющих символов получают апостроф при экспорте по умолчанию; поведение зависит от табличного приложения. Режим без защиты отключает эту меру.

Ограничения: файл — 2 000 000 байт; вставка — 2 000 000 символов; максимум 50 000 элементов; глубина от корня (0) — максимум 128.
