JSON to CSV

JSON is processed locally in the browser; conversion code does not send it to an application server.

Limits shown before input: file up to 2,000,000 bytes; pasted text up to 2,000,000 characters; 50,000 values; depth from root (0) max 128; CSV up to 250 columns and 50,000 cells including the header. Reduce records or fields if exceeded.

A root object is one record; an array of objects is multiple records. Nested objects use dotted paths; arrays and empty objects remain JSON. null and missing fields become blank cells. Keys use native JavaScript enumeration: integer-index keys ascending numerically, then other keys in insertion order; union columns follow first appearance. Native JSON parsing keeps the last value when an object repeats a member name.

Formula-like strings are prefixed with an apostrophe on export. This is not a guarantee for every spreadsheet; unsafe mode disables the mitigation.
