XML to CSV

XML is processed in the browser; this tool's conversion code does not send XML to an application server.

Missing values are blank; nested fields use dotted paths and repeated values are kept as JSON.

Formula-like cells after leading whitespace or control characters are prefixed with an apostrophe on export. Spreadsheet behavior may vary; raw export disables this mitigation.

Limits: files up to 2,000,000 bytes; pasted XML up to 2,000,000 characters; at most 50,000 elements; descendant depth max 128.
